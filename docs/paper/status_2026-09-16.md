## 1. The claim, link by link

The project's bet: a world model that explicitly represents *"what agent A does
changes what happens to agent B"* will predict better, rank plans better, and
control better than models that do not.

| Link | Verdict | Confidence |
|---|---|---|
| 1. Predicting unseen action combinations | **Works on Buzz Wire, replicates on a second bank. Does not replicate on Balance.** | Medium — was High before 1233 |
| 2. Better plan ranking | **Task-dependent, and the architecture that wins flips between tasks** | Low |
| 3. Better control | **Not measured.** The objective used for three months was task-orthogonal | High that it is unmeasured |
| 4. Benefit tracks physical coupling | **Weakened.** Two of four tasks have no measurable coupling at all | Low |

Links 3 and 4 moved this week, both downward, both for measurement reasons rather
than model reasons.

## 2. Link 1 — counterfactual prediction

Intervention response, **lower is better**, 1.0 = no better than predicting no
change at all. Eight seeds, paired on identical anchors.

| Task | Bank | joint | relational | Active anchors |
|---|---|---:|---:|---:|
| Buzz Wire | dev, λ=0.09 | 0.766 / 0.870 | **0.731 / 0.739** | 113 / 117 |
| Buzz Wire | dev, λ=0.009 | 0.781 / 0.900 | **0.650 / 0.741** | 113 / 117 |
| Buzz Wire | holdout | 0.327 / 0.427 *(ρ)* | **0.479 / 0.470** *(ρ)* | 110 / 115 |
| Transport | dev | 0.088 / 0.107 *(ρ)* | 0.063 / 0.020 *(ρ)* | **31 / 239** |
| Dropout | dev | — | — | **0 / 160** |
| Wheel | dev | — | — | **0 / 160** |
| Balance | dev | 1.696 / 2.105 | 1.185 / 1.267 | 113 / 197 |

Read the two failures in that table before the successes. **Dropout and Wheel
have zero interaction-active anchors** — their C7 is not a null result, it is
unmeasurable, and the paper must say so rather than reporting a null. **Transport
has 31 of 239**, which is why its numbers hover near zero for every model.

So link 1's dose-response claim rests on **Buzz Wire plus its holdout
replication**, and now has a contradicting case in Balance where both conditioned
models score **above 1.0** — worse than assuming no interaction.

**The regulariser gate (job 1228).** Every number in this project before 1228
used LeWM's default SIGReg weight of 0.09. At dim 192, dropping to 0.009 widens
the correlated relational-vs-joint gap from 0.035 to **0.131** and lowers rollout
error ~40% for all three models. Below dim 192, `joint` captures *nothing* at any
setting — the whole C7 result exists only at the largest width run.

## 3. Rollout error against horizon — and a hard architectural cap

Full tables: [`experiments/09_horizon_rollout.md`](experiments/09_horizon_rollout.md).

`ARPredictor.pos_embedding` is `(1, 6, 192)`, sized to the six-frame training
snippet. `MultiAgentWorldModel.rollout` **raises at block 6**. The world model
cannot predict beyond **25 primitive steps**, which caps the planner's horizon
regardless of how good the dynamics are. Extending it is a data-collection
change: the banks store six frames.

Transport, one block = 5 primitive steps, sliding-window rollout past h=5:

| predictor | h=1 | h=3 | h=5 | h=8 | h=15 |
|---|---:|---:|---:|---:|---:|
| independent (single-agent) | 0.0176 | 0.0323 | 0.0355 | **0.6628** | **1.1746** |
| joint | 0.0176 | 0.0272 | 0.0304 | 0.8579 | 1.4551 |
| relational | **0.0171** | **0.0252** | **0.0284** | 0.7207 | 1.2284 |

Three things this settles:

1. **The multi-agent advantage is a compounding effect, not a per-step one.** At
   h=1 the three predictors are indistinguishable and `joint` is marginally
   *worse*. The relational margin grows 14× between h=1 and h=5. Reporting
   `one_step_error` alone would have missed the effect entirely.
2. **h=5 → h=8 is a cliff, not a decay** — 18.7× in three blocks, exactly at the
   context boundary. Latent variance is 0.81 (Buzz Wire) / 0.90 (Transport), so
   by h=10 every model is at or past "no better than predicting the mean".
3. **Outside the trained window the ordering reverses** — the single-agent model
   is *best* at h≥8 on both tasks. The relational advantage should be claimed
   only inside the context window.

## 4. Link 3 — control was never measured

Full account: [`experiments/10_goal_objective.md`](experiments/10_goal_objective.md).
Every planner below uses the **true simulator** as its dynamics, so none of it is
a statement about a learned model.

| Design | Result |
|---|---|
| Random-plan goal endpoint (1218/1221/1226) | Goal oracle reaches it **20/20 on both tasks** and ends at the task distance random reaches (0.8993 vs 0.8988 Transport; 1.0937 vs 1.0852 Buzz Wire). **Orthogonal to the task** |
| Best-of-300 by task distance | Improves on candidate 0 by **0.0012** on Transport. Random actions make no task progress. Discarded |
| Competent-controller goal (1229) | Goal oracle collides **90%** vs random's 70%, finishes worse than doing nothing. Cancelled |
| Velocity dropped from the metric (1230) | 0.9841 task, 0.85 collisions. Unchanged. **Rejected** |
| Goals from solved episodes only (1231) | Beats random and do-nothing on the task (0.3658 vs 0.5029/0.5069), **2/20 native successes — the first ever**. Still 85% collisions. **Partial pass** |

**Consequence:** the claim that learned planners "close 30% (Buzz Wire) / 41%
(Transport) of the random → goal-oracle gap" is **withdrawn**. The gap is real;
crossing it changes nothing about the task.

**The mechanism, which is publishable on its own.** Buzz Wire agents observe
`[own pos, own vel, own pos − own goal]`. They never observe the ball, and never
observe the wire. A goal in that space can say *where the agents should be*; it
cannot say *do not let the ball touch the wire*, because no term in the objective
changes as the ball nears a wall. Reward planning sees the collision penalty;
goal planning is structurally blind to it. On identical states the reward oracle
scores **17/20** and the goal oracle **2/20**.

This generalises past this project: any observation-space goal on a task whose
failure mode is unobserved carries this hazard, and the diagnostic is cheap —
score the goal oracle on the task's own metric and its collision rate, not only
on goal distance.

**Do-nothing beats random on goal distance in every table above.** That baseline
is the audit's contract item 5; it had never been run, and it would have caught
the original design on day one.

## 5. Stage 2 and Balance agree: structure substitutes for information

**Stage 2 (job 1223)** — 144 runs, Buzz Wire, three inputs × three predictors ×
eight seeds. Rollout error, best cell per input:

| input | best | joint vs relational, paired |
|---|---|---|
| observation (6 dims) | 0.2429 relational | relational wins **7/8, 7/8** |
| history (18 dims) | 0.2315 relational | relational wins **6/8, 8/8** |
| physical (24 dims) | **0.1888 joint** | **joint** wins 6/8, **8/8** (−0.0543, p≈0.008) |

Information helps by 22% (0.2429 → 0.1888), and the architecture ordering
**reverses** once the hidden state is supplied.

**Balance (job 1233)** reaches the same conclusion by a different route. Balance
observes the package position, its goal offset, its velocity and the full line
state natively — it *is* the "information present" condition, arrived at by
changing the task rather than the input. Plan ranking, independent regime:

```
joint        spearman +0.0863  [+0.0715, +0.1008]  8/8     regret -0.843  8/8
relational   spearman +0.0135  [+0.0025, +0.0230]  6/8     regret -0.142  4/8
```

Joint wins decisively; relational is marginal. The reverse of Buzz Wire.

**The hypothesis both support:** *relational structure compensates for
unobservable coupling, and stops paying — or reverses — once the coupling
variable is observed.* The outline called this "attractive and currently
unconfirmed" because the Stage 2 version sat inside the F6 cross-latent-space
confound. Balance is not subject to that confound: different task, different
bank, shared-target probe.

## 6. The unresolved tension

On Balance's **same checkpoints**, three metrics disagree:

| Metric | Winner |
|---|---|
| Counterfactual prediction error, paired | **relational** (6/8, 7/8 seeds) |
| Intervention response ratio | **neither** — both above 1.0 |
| Stratified concentration on active anchors | **relational** (−2.8 points, CI [−4.2, −1.3]) |
| Plan ranking Spearman and regret | **joint** (8/8 seeds) |

This must be resolved before anything is written. Relational predicts the
counterfactual *state* better and its advantage concentrates where interaction
happens, yet it fails to capture the interaction *response* and does not convert
to plan ranking. Leading with any one of these without the others would be
selective reporting.

## 7. Task suite health

Two of the four original tasks cannot support the claims they were chosen for.

| Task | Status |
|---|---|
| Buzz Wire | Agents observe neither the ball nor the wire. Goal objective structurally blind to the failure mode. Coupling measurable (113/117 anchors) |
| Transport | **Uncontrollable from its anchors** — VMAS's own heuristic closes 0.032 of the starting 0.9006 across a full 100-step episode; doing nothing loses 0.0012. Its universal 0/20 native success is not evidence about any model. Coupling barely measurable (31/239) |
| Dropout | **0 interaction-active anchors.** C7 unmeasurable |
| Wheel | **0 interaction-active anchors.** C7 unmeasurable |
| **Balance** *(new, job 1233)* | Task state fully observed; heuristic scores **+43.44** vs random's −22.09 and zero-action's −5.75; **113/197 anchors active**. The only healthy task in the suite |

Six VMAS candidates were probed over 64 episodes before Balance was chosen. Only
Balance had both an observable task state and a shipped competent policy. The
next best candidate is **`navigation`** — the only VMAS task where agents
**observe each other** (lidar over other agents), which every task used so far
hides completely. Its heuristic is a CBF/CLF quadratic program requiring `cvxpy`,
not currently installed.

## 9. What must not be claimed

* That learned planners achieve any measure of control. They do not, and until
  1231 the objective could not have shown it either way.
* That the relational advantage is general. It holds on Buzz Wire, replicates on
  its holdout, and **fails to replicate on Balance**.
* That coupling dose-response holds across four tasks. Two of the four have no
  measurable coupling.
* Any C7 number from before the F6 repair (job 1224), or any rollout-horizon
  claim past **h=5**, where the model is extrapolating outside its context.

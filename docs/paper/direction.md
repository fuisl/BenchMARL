# Counterfactual Joint-Action Prediction for Multi-Agent Latent MPC

The entire paper asks essentially one question:

> **Can a simple latent world model plan cooperative multi-agent actions reliably when the planner considers joint actions that were not observed together in the training data?**

That is the problem I would pursue.

## Why This Is Specifically Multi-Agent

LeWM learns something roughly like

```math
z_{t+1}=f(z_t,a_t).
```

In multi-agent control, that becomes

```math
z_{t+1}^{i}
=
f\left(
z_t^i,a_t^i,
\{z_t^j,a_t^j\}_{j\neq i}
\right).
```

The crucial difference is the **other agents' actions**.

During offline training, you observe particular coordinated joint actions:

```math
(a^1,a^2,a^3,\ldots).
```

But MPC deliberately asks:

> "What if agent 1 does this, while agent 2 instead does that?"

Those combinations may never have appeared in the dataset. A world model can therefore have excellent ordinary next-state prediction while giving the planner completely wrong counterfactual futures. This exact issue is identified in the second proposal: low prediction error on behaviour-policy trajectories does not guarantee correctness under the counterfactual joint actions generated by MPC.

That gives you a **real MARL problem**, rather than "take LeWM and add multiple agents."

## Research Question

I would make the main RQ:

```math
\boxed{
\textbf{RQ: Does interaction-aware joint-action prediction improve}
}
```

```math
\boxed{
\textbf{latent plan ranking and closed-loop control in cooperative multi-agent MPC?}
}
```

And perhaps only one secondary question:

```math
\boxed{
\textbf{Does multi-step training matter more as agent interaction increases?}
}
```

No five RQs. No foundation-model question. No role-collapse question. No decentralisation question.

The proposal itself already identifies essentially this RQ as particularly fundamental: whether multi-step joint-action prediction improves counterfactual MPC reliability over one-step teacher forcing.

## Proposed Method

The method can be almost embarrassingly small.

Use a **LeWM-style two-term model**:

```math
\mathcal L =
\mathcal L_{\text{prediction}}
+
\lambda\mathcal L_{\text{SIGReg}}.
```

LeWM's attraction is precisely that it eliminates the decoder, reward model, KL objectives, target encoder, etc.; the document contrasts this simplicity with substantially more complicated MARL world models.

The only real multi-agent modification is the predictor:

```math
m_i=\sum_{j\neq i}
\phi(z_t^i,z_t^j,a_t^i,a_t^j)
```

```math
\hat z_{t+1}^{i}
=
f(z_t^i,a_t^i,m_i).
```

That is the complete model change.

Then use **centralised CEM-MPC**:

```math
A^*_{t:t+H}
=
\arg\min_A
d(\hat Z_{t+H}(A),Z_g).
```

The planner searches joint actions; the relational model predicts their consequences.

No policy learning is necessary for the core paper.

## Minimal Experiment

Use **VMAS vector observations**, not images initially. Your first-stage document already recommends VMAS/JaxMARL and explicitly says to prove the multi-agent latent model/planner before introducing foundation visual features.

I would compare only three world models:

| Model | What it knows |
|---|---|
| **Independent LeWM** | $z_i,a_i$ only |
| **Joint LeWM** | concatenated $Z,A$ |
| **Relational MA-LeWM** | shared agent model + interactions |

Same data. Same latent size. Same loss. Same CEM planner.

Use perhaps **2–4 agents** and **2–3 VMAS tasks** chosen to vary interaction strength: one weakly coupled task and one strongly cooperative task.

Then measure two outcomes above all:

1. **Plan-ranking accuracy**
2. **Actual MPC success or return**

Plan ranking is especially important. The document makes the useful observation that a world model exists to tell the planner **which candidate future is better**, not merely to minimize one-step MSE.

So you can have the wonderfully clean result:

```math
\text{similar prediction MSE}
```

but

```math
\text{Relational WM}
>
\text{Independent WM}
```

for counterfactual plan ranking,

and consequently

```math
\text{Relational MPC}
>
\text{Independent MPC}.
```

**That is a paper.**

## Central Hypothesis

I would phrase the hypothesis this narrowly:

> **Multi-agent latent planning fails not necessarily because the world model predicts poorly, but because it predicts poorly under counterfactual joint actions. Explicit relational joint-action conditioning can reduce this planning error without requiring a more complicated world-model objective.**

I like this considerably more than the current **"foundation-initialised MA-LeWM + TC-SIGReg + agent scaling + uncertainty + decentralisation"** proposal.

It isolates exactly **one** thing that changes when going from one agent to multiple agents:

```math
\boxed{\text{actions affect other agents}}
```

and asks whether the world model must explicitly represent that dependency for planning to work.

The first document actually advises the same ordering: **do not introduce foundation visual features until the factorised/interaction model demonstrably predicts counterfactual interactions better than independent dynamics.**

## Out of Scope

To keep the first version focused, leave out:

- Foundation models and V-JEPA/DINO initialization
- Visual inputs
- Heterogeneous roles
- TC-SIGReg as a novel contribution
- Uncertainty modelling
- CTDE and decentralised execution
- Communication learning
- Variable team sizes
- MCTS and policy distillation
- Massive baseline suites

Those are all tempting. They also obscure the scientific question.

For the first version, I would aim for something almost **LeWM-simple**:

```math
\boxed{
\text{VMAS}
+
\text{2-term latent WM}
+
\text{relational joint dynamics}
+
\text{CEM}
}
```

with one clear finding:

```math
\boxed{
\text{interaction modelling}
\rightarrow
\text{better counterfactual prediction}
\rightarrow
\text{better plan ranking}
\rightarrow
\text{better multi-agent control}.
}
```

That is the direction I would develop next. It is narrow enough that we can now work **line-by-line from the mathematical problem formulation → exact architecture → loss → dataset construction → counterfactual evaluation → experiments**, without adding anything unless it is necessary.

# Research direction review — 16 September 2026

**Recommendation: continue toward counterfactual multi-agent control, but repair the evidence and establish one working Balance control experiment before changing the model family.** The present results do not identify relational dynamics as the main blocker. They mix objective mismatch, weak control feedback, deficient coverage, representation-dependent measurements, and two newly reproduced implementation defects. In particular, the reported long-horizon collapse is substantially affected by an evaluation error, and Balance's supposedly competent source policy was the wrong task's policy.

This review starts from [status §1 and §9](status_2026-09-16.md), then follows the goal/horizon notes, experiment index, audit, direction documents, saved results, submitted source copies, and current implementation. It distinguishes saved experimental results, new CPU diagnostics, hypotheses, and proposed experiments. Code inspected at commit `cf70fa933de41aa3e040ddc7680a3ac37feb7f4a`; installed VMAS is 1.5.2. Primary research sources were checked on 16 September. No training sweep was launched and no experimental implementation or checkpoint was changed.

**What to do next, in one paragraph.** Fix scenario-specific heuristic dispatch, provide Balance-specific outcome/goal handling, repair the horizon diagnostic, and replace cross-model latent comparisons with common physical response measurements. Then validate task-aligned simulator MPC on Balance with five-step feedback. Collect competent trajectories plus controlled interventions around useful states, establish a simple physical-state dynamics baseline, and compare independent, joint, and relational models under the same scorer and planner. Only after that should latent geometry, multi-step losses, or energy models become the next intervention. A joint model winning is a useful answer to the research question.

**2. Newly confirmed defects change the priority order.**

**Balance's heuristic data came from Transport's policy.** The collector imports `vmas.scenarios.transport` and instantiates its `HeuristicPolicy` for every heuristic source trajectory. The defect is present in both [current collector](../../examples/world_model/collect.py#L463) and [job 1233's submitted copy](../../outputs/balance_1233/source/collect.py#L463). Loading the correct scenario module elsewhere in collection only records its provenance; it does not select its policy.

Verification used all **30,824 valid agent-actions** in the saved Balance heuristic trajectories:

| Policy recomputed from the saved observations | Mean absolute action difference | Actions matching within 1e-5 |
|---|---:|---:|
| Transport heuristic | 1.46e-9 | 100% |
| Balance heuristic | 1.0795 | 0% |

The mislabeled policy supplies **426 of 1,620 anchors**. On the same first 64 saved initial states, stored mean per-agent return is **−15.6391**; a CPU replay with the correct Balance policy gives **+9.5601**. This is a diagnostic comparison, not a replacement benchmark: the original collection used CUDA, and this is a subset of roots. It establishes the source-policy error and a substantial practical difference, not the final Balance success rate. The status's earlier +43.44 reference came from a different probe and should not be substituted for these matched-root numbers. [Diagnostic evidence](../../outputs/review_20260916/evidence.json)

**Consequence:** preserve job 1233 as a valid result on the dataset actually generated, but withdraw the description of that bank as containing competent Balance heuristic behavior. Its physics labels and model comparisons are not all invalidated; its intended coverage argument is. Fix dispatch through the selected scenario's policy, test stored actions against that policy, and create a new versioned bank.

Also, `include_heuristic=true` currently adds heuristic **anchor states**. The training loader still reads random correlated/independent branches, not the saved competent action trajectories. Correct dispatch alone will not teach sustained lifting or other useful action sequences. The next collection should deliberately include both competent segments and controlled deviations from them, with mixture proportions recorded.

**The reported horizon cliff is strongly contaminated by an unused positional slot.** Training encodes six frames but predicts from `latent[:, :-1]`: five predictor positions receive prediction supervision. The allocated positional embedding has six entries. The [horizon evaluator](../../examples/world_model/horizon_rollout.py#L101) uses the allocation length as its context size, introducing position 5 at prediction block 6. That position receives no prediction gradient; weight decay is not prediction training. [Training loss](../../examples/world_model/train.py#L104), [predictor](../../examples/world_model/models.py#L149)

A direct gradient check gave nonzero norms for positions 0–4 and exactly zero for position 5. The ordinary rollout succeeds through six blocks and raises at **block seven**, so the documentation's “raises at block six” is also off by one. More importantly, the already-existing goal rollout uses a three-position sliding context: a universal 25-step architectural cap was never justified across both planning paths.

Using the same Transport actions and truth, one correlated-data checkpoint per architecture, seed 4100, and the bank's 16 held-out root starts:

| Predictor | h=5, either window | h=15, window of 6 | h=15, window of 5 |
|---|---:|---:|---:|
| Independent | 0.05655 | 1.27194 | 0.07386 |
| Joint | 0.04603 | 1.48590 | 0.06477 |
| Relational | 0.04011 | 1.23006 | 0.06090 |

Each row compares one checkpoint to itself; it therefore avoids using different latent spaces to measure the effect of changing the window. No weights were changed. Three-position windows also avoid the large cliff. This strongly implicates the positional mismatch in the published curve. It does **not** establish reliable long-horizon physical prediction, control, or a replicated architecture ordering. [Full values and protocol](../../outputs/review_20260916/evidence.json)

**Next action:** rescore the existing checkpoints with trained context lengths, report physical error and decision regret, and only then decide whether longer data are necessary. Longer training may still help; it is not the first repair justified by this result.

**The closed-loop entry point does not yet support Balance outcomes.** In [closed_loop.py](../../examples/world_model/closed_loop.py#L572), every task except Transport uses `buzz_wire_outcome`, which accesses `scenario.ball`. Balance has `scenario.package`; a direct call reproduces `AttributeError: 'Scenario' object has no attribute 'ball'`. Its position-goal masking is unsupported too. This did not affect job 1233, which ran open-loop evaluations, but it would block the proposed next control run.

Implement an explicit Balance outcome adapter: package-goal overlap for task completion, `on_the_ground` as failure, and package-goal distance as progress. Define precedence if completion and failure coincide. Its native `done()` includes both success and failure, so counting `done` as success would introduce another serious measurement error. **3. Balance's metric disagreement is not yet evidence of a scientific paradox.**

The saved active-anchor counterfactual table reports the following **own-latent** absolute errors:

| Training regime | Joint E_CF | Relational E_CF |
|---|---:|---:|
| Correlated | 0.34231 | 0.36768 |
| Independent | 0.35441 | 0.38586 |

The raw values are lower for joint. These are different target spaces, so even that numeric ordering is not a common-physical-accuracy result. The paired gap table compares each conditioned model against **independent**, and the stratified concentration table also compares **relational against independent**. Neither establishes that relational predicts physical state better than joint. [C7 output](../../outputs/balance_1233/counterfactual.txt), [stratified output](../../outputs/balance_1233/stratified.txt)

The own-space response ratios above one do say something useful: on this intervention, each conditioned model predicts its own latent response worse than assuming zero response. But the “shared physical probe” only correlates **latent response magnitude** with **observation response magnitude**. It does not decode a physical vector or check response direction. A prediction pointing in the opposite direction can have perfect magnitude ranking. It cannot complete the audit's requested physical-response validation.

The F6 repair is also incomplete: the last [C7 paired-response table](../../examples/world_model/counterfactual_evaluation.py#L311) still subtracts raw response errors from different encoders. Relative reductions in [stratified_evaluation.py](../../examples/world_model/stratified_evaluation.py) do not automatically remove this problem either. Keep own-space ratios as diagnostics; use common physical targets for cross-model claims.

There is no mathematical requirement that endpoint accuracy, intervention-response accuracy, and reward ranking agree. A model can predict a nearly correct absolute state while inventing a small action-induced change, or preserve reward ordering while mispredicting irrelevant coordinates. Ranking depends especially on errors relative to the margins between promising candidates. The right next comparison uses **the same anchors, candidate actions, horizon, physical outputs, and task cost** throughout.

Several stronger statements should be narrowed as well:

- Transport's tested controllers made little progress from the selected anchors. This does not prove those states are uncontrollable or that Transport can never support control.
- An endpoint goal omits path safety even in a fully observed task. Buzz Wire's partial observations add difficulty, but failed endpoint-goal MPC does not prove that every possible goal-conditioned controller must fail.
- Balance exposes useful object variables; that does not by itself establish full Markov sufficiency. Its local observations still omit other agents' states, and angle wrapping needs care.
- Zero active Wheel anchors applies to one agent, one action axis, the selected anchors, and the measured horizon. It is not a task-wide absence of interaction.
- Stage 2's claimed 22% improvement compares separately learned latent errors. It is not yet a 22% improvement in physical prediction.

**4. Planning and control are real blockers, but they can be isolated cheaply.**

The existing code still sets executed blocks equal to the planned horizon: [closed_loop.py:525](../../examples/world_model/closed_loop.py#L525). At H=5 and block size 5, all 25 primitive actions are executed before new feedback. There are at most four decisions in a fresh 100-step episode and fewer from late anchors. Shifting away the entire plan makes the nominal warm start all zeros. This is a particularly unfavorable setting for contact, balance, and collision avoidance.

Use **H=5 blocks, execute one block** as the first controlled change. That gives feedback every five primitive steps while retaining the current model/action representation. One-step feedback is a later experiment requiring support for partial block execution and history alignment. Report both budget per decision and total episode compute: changing cadence increases planning calls, so equal calls per decision is not equal episode cost.

The action block is a representation grouping, not an action-repeat constraint. Five blocks still contain **100 free scalar controls for two agents**, or **200 for four agents**. Independent noise at every primitive time can be poor at proposing sustained cooperative motion. After fixing cadence, test temporally smooth proposals, retained elites, and a useful warm start at a matched total evaluation budget. These changes are directly motivated by [iCEM](https://proceedings.mlr.press/v155/pinneri21a.html).

There is another unresolved search risk: CEM executes the **mean of the final elites**, which has not itself been scored at that final update. The best-seen cost in logs is not the cost of the executed mean. Averaging two safe modes can produce an unsafe or ineffective plan. Compare the rescored final mean with the best sampled plan using the **planner's own** cost; use simulator scoring only as a diagnostic, not to select actions for a learned-model policy. [CEM return](../../examples/world_model/cem.py#L164)

Run the following decomposition before attributing failure to architecture:

| Comparison on identical candidates | What failure would identify |
|---|---|
| True simulator + native/task-aligned cost, executed in closed loop | Objective/search/cadence/reference competence |
| True rollout endpoints/paths + proposed goal cost versus native cost | Whether the goal objective represents progress and failure |
| True trajectories + encoded goal cost or physical probe | Representation and cost geometry |
| Predicted trajectories + exactly the same scorer | Dynamics and accumulated rollout error |
| Fixed random candidates versus CEM intermediate/final candidates | Distribution shift induced by optimization |

Use native return, success, ground/contact failures, physical goal progress, selected-plan regret, and compute. A goal-distance improvement alone is insufficient. For path-dependent tasks, score failure over the rollout or use a separately validated failure predictor; a terminal state distance cannot substitute for it.

**6. Make the counterfactual question more precise.**

There are two different claims:

1. **Conditioning:** other agents' states/actions improve predictions and decisions over a model that lacks those inputs.
2. **Factorization:** at the same information, data, and capacity budget, relational structure generalizes better than an unrestricted joint predictor.

Independent versus joint addresses the first; joint versus relational addresses the second. Independent has an exactly zero cross-agent action response by construction, so outperforming it alone is not strong evidence of recovered interaction mechanisms. Also compare a model given joint state but **only the queried agent's action**, isolating missing action information from missing state information.

The present correlated regime matches action marginals but excludes opposite signs **inside every agent pair**. The relational message function consumes `(z_i,z_j,a_i,a_j)`, so its own local input combinations are held out too. With only two agents, that pair already contains the complete joint action. This is an extrapolation test, not a clean test of recombining already-covered pair mechanisms. [Sampler](../../examples/world_model/collect.py#L95), [conditioner](../../examples/world_model/models.py#L211)

A stronger optional test uses at least three agents and checks that each relevant local factor has training support while some global combinations remain held out. For example, a four-agent sign-parity split can cover every pair's sign combinations while withholding half of the global sign patterns. This is only an illustrative action-design check: it does not establish support for state-dependent contacts, magnitudes, temporal patterns, or shared-object factors. Measure those too. Local-support assumptions are central to the relevant generalization arguments in [MoCoDA](https://proceedings.neurips.cc/paper_files/paper/2022/file/7314e20a73542bbfff25030d1185ce88-Paper-Conference.pdf); a generic GNN does not inherit that theorem.

For the immediate experiment, define a common physical output `Y`: non-intervened agent position/velocity, shared-object position/velocity, signed angular motion where relevant, and task failure. From exactly the same restored state, compare a reference joint plan A with an intervened plan A'. Define `ΔY = Y(A') − Y(A)` and score predicted differences in the same coordinates:

```
response ratio = sum ||(predicted ΔY − true ΔY) / training_scale||²
                 / sum ||true ΔY / training_scale||²
```

Zero-response prediction has ratio one. State scales must be fitted on training data and fixed across models. Report numerator, denominator, active-anchor count, absolute physical errors, and direction agreement. Treat tiny denominators as uninformative instead of manufacturing stable ratios. Fit any model-specific physical probes on training roots, select their settings on validation roots, and test held-out roots. Probe error on true encodings must be reported separately from prediction error.

Intervene on different agents and both action axes, including short sustained and paired deviations. In Balance, y-force directly relates to lifting; the current x-only probe need not reflect the dominant task decision. For a two-agent intervention, the mixed difference `Y(A_ij) − Y(A_i) − Y(A_j) + Y(A)` tests non-additive effects, rather than merely detecting any response.

Keep failure-changing interventions in a separate outcome analysis. Restricting every metric to pairs surviving both branches removes some of the most important safety counterfactuals. A changing success/failure event is itself a meaningful response, even when continuous endpoint comparison needs a terminal/absorbing-state convention.

**7. A small experiment sequence with explicit decisions.**

**Gate 0 — repair and audit, before another sweep.** Fix the policy dispatch and Balance adapter; preserve and label the old bank. Correct and rescore the horizon diagnostic. Audit the surviving F6 comparisons and terminal/event contracts. Separate planning and execution horizons. Add behavior checks for policy identity, terminal failure versus success, and use of trained context positions. These are scientific contract checks, not a new testing framework.

**Pass condition:** every reference policy, observation input, target, executed action, and terminal label has the advertised meaning. Passing the existing tests alone is insufficient; the wrong-policy bug was not caught by them.

**Gate 1 — make Balance controllable with true dynamics.** Start with roughly 32–64 independent development roots and compare zero action, random, the correct heuristic, and simulator MPC. Hold H=5 fixed and compare execute-five-blocks with execute-one-block. First use the native reward objective; separately test an explicit package-target cost with ground-failure handling if pursuing reward-free goals. Evaluate references from the same roots and time budget. Probe smooth proposals only if the corrected cadence remains inadequate.

**Pass condition:** simulator MPC produces repeatable native progress/success beyond trivial baselines, and the proposed task/goal objective agrees with native outcomes. If the heuristic works and simulator MPC does not, work on search/objective first. Freeze numerical acceptance thresholds on development data before touching the final test roots.

**Gate 2 — establish a common-coordinate world-model baseline.** Use the repaired Balance data, including competent segments and interventions. Fit a simple residual model of physical state changes, with independent/joint/relational conditioning variants and one fixed analytic task scorer. This deliberately introduces physical supervision as a diagnostic baseline; label that difference from reward-free latent learning. It removes learned encoder geometry and reward-head quality from the first question: can learned joint dynamics support the validated controller at all?

For the existing latent models, fit the common physical probes and repeat the same candidate-cost decomposition. A frozen shared encoder is a useful separate architecture control. Do not compare separately learned latent MSEs as if they were physical errors.

**Pass condition:** joint or relational prediction beats zero-response on decision-relevant interventions and reduces common-cost selected-plan regret versus independent. If the physical model works but latent models fail, representation/cost geometry is the bottleneck. If all learned models fail with a successful oracle, inspect coverage and multi-step physical errors.

**Gate 3 — test coverage before adding model complexity.** On matched anchor states and transition budgets, compare competent-local actions with controlled individual/pair deviations and broader independent actions. Start with one targeted coverage contrast, not a factorial sweep. Audit contact, useful progress, event incidence, and local-factor support. Keep all descendants of a root episode in one split. Test response and regret on the same intervention bank.

**Pass condition:** increased relevant support improves response accuracy and selected-plan regret, not just logged prediction loss. If relational benefits most at smaller budgets and joint catches up with more coverage, a data-efficiency finding is stronger than a universal architecture claim.

**Gate 4 — measure actual learned control.** Use exactly the admitted task, objective, inputs, horizon, cadence, and search budget. Run all three model families plus the reference policies. Start with a three-seed pilot; expand only a functioning comparison to the established eight-seed convention and a second independent data bank. Measure native success, failures, return, physical progress, regret, and wall-clock cost. Final evaluation should use fresh root episodes, not repeated selected anchors from the small development bank.

**Pass condition:** a conditioned world model produces a paired native-control benefit over independent, with uncertainty over roots and training seeds. For a relational-specific claim, it must also beat joint under matched information and selection budgets. A gain over random alone is too weak to identify an interaction benefit.

**Gate 5 — choose the next model change from the remaining failure.** If physical rollout error compounds despite corrected context, try a targeted multi-step consistency loss. If true encoded endpoints already rank poorly, address the decision metric or add task-relevant supervision. If CEM finds implausible plans despite reasonable random-bank scores, investigate search-distribution data or reliability penalties. Each intervention should follow its diagnostic; do not simultaneously change data, loss, architecture, and planner.

Keep λ=0.009 as a promising **Buzz Wire** setting, not a universally selected optimum. Select regularization on held-out physical response and decision quality with equal tuning budgets across architectures. Balance currently used 0.09. The 192-dimensional result may reflect a representation/optimization regime; it is not proof that low-dimensional physics intrinsically requires a 192-dimensional latent.

The “structure substitutes for information” idea is particularly close to the July 2026 preprint's partial-observation findings. It should not be presented as an established new mechanism from two uncontrolled task comparisons. A clean within-task observation intervention followed through to decision quality would be much stronger.

**9. How to spend the next research window.**

For the first one to two working days, prioritize Gate 0 and the small simulator-control gate. The most useful immediate result is a corrected Balance oracle table and a corrected horizon curve, not another 48-model sweep. The next few days should establish the physical baseline and common-space scoring. Expand to more seeds, a second bank, or a second task only after those results tell you which failure remains. These are working priorities, not guaranteed runtimes.

For publication, retain the diagnosis route as a fallback, but do not freeze its current causal story: a diagnostic paper built around an artificial horizon cliff or mislabeled competent data would repeat the very problem it describes. The durable contribution is the controlled connection between intervention coverage, physical response, candidate regret, and native control, including cases where an unrestricted joint predictor is sufficient.

A defensible eventual headline would be: **“Decision-relevant intervention coverage enables joint-action world models to improve multi-agent planning; relational structure helps under specified information and data constraints.”** Every clause is a hypothesis to test. If only the first part survives, report it. If learned control remains absent, write the measured protocol/failure decomposition without claiming that prediction improvements cause control improvements.

The practical success condition is a world model that helps choose better joint actions on an honestly validated task. Whether the winning model is relational, joint, or a simpler state predictor is an outcome of that work.
